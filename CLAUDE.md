## Продукт
**Saq** (каз. «сақ» — бдительный) — ИИ-щит от мошенников ДО перевода денег.
Банковский антифрод ловит транзакцию. Saq ловит момент, когда человека ещё уговаривают.

1. **Проверка** — вставь текст / скрин переписки / опиши звонок → вердикт за секунды:
   риск 0–100, название схемы (ложный звонок «службы безопасности», фейк-магазин, лжеинвестиции,
   «мама, я в беде», взлом аккаунта, кредит на тебя), **подсвеченные фразы-манипуляции с объяснением**,
   что делать прямо сейчас. Кнопка «Прочитать вслух» (для бабушек) и «Отправить внуку» (WhatsApp).
2. **Прививка** (главная фишка) — ИИ безопасно играет мошенника в чате по реальной схеме.
   Пользователь должен распознать обман. В конце — разбор: какие красные флаги заметил / пропустил, балл.
   Для школ и пожилых: тренировка вместо лекции.

## Стек
- Vite + React + TypeScript, Tailwind v4 (`@tailwindcss/vite`), `motion`.
- 3D: `three` + `@react-three/fiber` + `@react-three/drei` — сфера-индикатор риска (MeshDistortMaterial, цвет зелёный→жёлтый→красный, сильнее искажается при высоком риске).
- `api/check.ts`, `api/sim.ts` — Vercel functions → Google Gemini Flash (текст + vision). Ключ только в env `GEMINI_API_KEY` (модель — `GEMINI_MODEL`). Запасной провайдер: `ANTHROPIC_API_KEY`.
- Озвучка в приложении: Web Speech API (`speechSynthesis`, ru-RU) — бесплатно, без ключа.
- «Отправить внуку»: `https://wa.me/?text=` — без бэкенда.
- Без БД. История проверок — localStorage.
- Деплой: Vercel из GitHub.

## Безопасность (критерий 3)
- Ключ AI только на сервере.
- Сервер: лимит текста 4000 символов, картинка `image/jpeg|png|webp` ≤ 4 МБ, ответ ИИ валидируется как JSON с ожидаемыми полями.
- Скрины сжимаются canvas до 1280px → удаляются EXIF/метаданные. Ничего не храним на сервере.
- Промпт сим-режима: только учебный диалог, никаких реальных номеров/ссылок/реквизитов, после 6 ходов — разбор.
- Без ключа или при ошибке API → фолбэк на правила по ключевым словам (`fallback: true`), демо не ломается.
